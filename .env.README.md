# Environment Configuration

PyMerlin uses environment variables to locate build dependencies. Create a `.env` file in this directory to customize paths for your environment.

## Setup

```bash
# Copy the example file
cp .env.example .env

# Edit .env with your paths
nano .env
```

## Variables

### `PLANDEV_PATH`
**Required for:** Building mission model JARs

Path to the plandev (Aerie) repository containing built JARs.

**Default search locations (if not set):**
1. `~/Desktop/pymerlin/plandev`
2. `~/Desktop/plandev`
3. Relative to pymerlin: `../plandev`

**Example:**
```bash
PLANDEV_PATH=~/code/aerie/plandev
```

---

### `PYMERLIN_CODEGEN_JAR`
**Required for:** Building mission model JARs

Path to the `pymerlin-codegen.jar` file (built from `java/pymerlin-codegen`).

**Default:** `java/pymerlin-codegen/build/libs/pymerlin-codegen.jar` (Gradle's output location)

**Example:**
```bash
PYMERLIN_CODEGEN_JAR=~/Desktop/pymerlin/pymerlin/java/pymerlin-codegen/build/libs/pymerlin-codegen.jar
```

---

### `PYMERLIN_VENV`
**Required for:** Building mission model JARs (for py4j.jar)

Path to the Python virtual environment containing py4j.

**Default search locations (if not set):**
1. Relative to pymerlin: `../venv`
2. `~/Desktop/pymerlin/pymerlin/venv`

**Example:**
```bash
PYMERLIN_VENV=~/Desktop/pymerlin/pymerlin/venv
```

---

## Example `.env` file

```bash
# PyMerlin Build Configuration
# Copy this file to .env and adjust paths for your environment

# Path to plandev directory (Aerie source)
PLANDEV_PATH=~/Desktop/pymerlin/plandev

# Path to pymerlin-codegen.jar (built from java/pymerlin-codegen)
# Default: java/pymerlin-codegen/build/libs/pymerlin-codegen.jar
PYMERLIN_CODEGEN_JAR=~/Desktop/pymerlin/pymerlin/java/pymerlin-codegen/build/libs/pymerlin-codegen.jar

# Path to Python virtual environment (for py4j.jar)
PYMERLIN_VENV=~/Desktop/pymerlin/pymerlin/venv
```

## Troubleshooting

### "Cannot find plandev directory"
- Set `PLANDEV_PATH` in `.env`
- Ensure plandev JARs are built: `cd $PLANDEV_PATH && ./gradlew build`

### "package gov.nasa.ammos.aerie.merlin.python.codegen does not exist"
- Build pymerlin-codegen: `cd java && ./gradlew :pymerlin-codegen:jar`
- Set `PYMERLIN_CODEGEN_JAR` to the built JAR location

### "py4j*.jar not found"
- Ensure py4j is installed: `pip install py4j`
- Set `PYMERLIN_VENV` to your virtual environment path
